# Sistema de Controle de Estoque

Projeto desenvolvido em Python para gerenciamento de estoque.

O sistema permite cadastrar, consultar, listar e atualizar produtos, além de controlar entradas e saídas de estoque.

Funcionalidades

* Cadastro de produtos
* Listagem de produtos
* Consulta de produtos
* Atualização de estoque
* Exclusão de produtos
* Registro de entrada de mercadorias
* Registro de saída por venda
* Validação de dados
* Armazenamento de informações em arquivo JSON

Tecnologias utilizadas

* Python
* JSON
* Git
* GitHub
* Visual Studio Code 

Como executar o projeto

1. Clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo main.py pelo terminal.

python main.py
